# Hands-On-Machine-Learning-with-Scikit-Learn-Keras-and-TensorFlow

This is a repository for the book Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow.

Objective: To understand the fundamentals of machine learning and deep learning, and to be able to apply them to real-world problems. As a AI engineer, I want to be able to understand the fundamentals of machine learning and deep learning, and to be able to apply them to real-world problems. 

Furthermore, I believe that I am still noob of the fundamentals of machine learning and deep learning, so I want to use this book to improve my knowledge and skills.

## Chapters Overview

### Chapter 10: Introduction to Artificial Neural Networks with Keras
Introduces the basics of Artificial Neural Networks (ANNs) and how to implement them using the high-level Keras API. It covers building and training simple models, such as Multi-Layer Perceptrons (MLPs), for classification and regression tasks.

### Chapter 11: Training Deep Neural Networks
Focuses on the challenges of training deep neural networks, such as vanishing and exploding gradients. It explores techniques like weight initialization, batch normalization, gradient clipping, and advanced optimizers (e.g., RMSprop, Adam) to speed up training and improve model performance.

### Chapter 12: Custom Models and Training with TensorFlow
Dives deeper into the lower-level TensorFlow API. It explains how to create custom loss functions, metrics, layers, and even full models. It also covers custom training loops and how to use `tf.data` for efficient data loading and preprocessing.
